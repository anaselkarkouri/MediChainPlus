Projet universitaire · EMSI 2025 / 2026

Une infrastructure blockchain hybride pour la santé numérique

MediChain+ unifie Hyperledger Fabric, Polygon EVM et IPFS derrière une seule API Gateway pour sécuriser les dossiers médicaux, automatiser les remboursements et tracer les médicaments.

Lancer la démo → Voir l'équipe

Architecture

Trois couches technologiques

Hyperledger FabricPatients, consentements, dossiers médicaux, prescriptions — chaincodes Go sur réseau 1-org / 2-peers.
Polygon EVMSmart contracts Solidity pour les remboursements automatisés et la traçabilité des médicaments (batch ID).
IPFSStockage distribué des fichiers médicaux chiffrés AES-256-GCM — CID stocké sur Fabric.
API GatewayExpress.js qui orchestre Fabric + EVM + IPFS, auth wallet challenge/signature, JWT.
FrontendApplication web multi-portails (patient, médecin, pharmacie, assureur) sans dépendance npm côté client.

Exigences F1 – F6

Périmètre fonctionnel

F1Le patient consulte son dossier et gère ses consentements.
F2Le médecin crée, consulte et signe les dossiers médicaux autorisés.
F3La pharmacie vérifie un médicament via batch ID / QR code et son historique on-chain.
F4L'assureur suit, valide et paie les remboursements via smart contract.
F5Authentification wallet (MetaMask) avec challenge/signature et JWT.
F6L'API Gateway orchestre tous les échanges entre les trois couches.

Livrables frontend

Quatre portails utilisateur

Patient

Consultation du dossier, gestion des consentements, suivi des prescriptions et remboursements.

Médecin

Création et consultation des dossiers médicaux, prescriptions, vérification d'intégrité IPFS.

Pharmacie

Lecture et dispensation de prescription, vérification et mise à jour du statut du médicament.

Assureur

Validation on-chain des réclamations, paiement automatisé, suivi des événements EVM.

Démonstration attendue

Critères de réussite

  • Flux complet patient → médecin → pharmacie → assureur exploitable en soutenance.
  • Dossiers médicaux sécurisés — fichiers sensibles stockés hors chaîne sur IPFS chiffré.
  • Remboursement soumis, validé et payé par smart contract Solidity.
  • Traçabilité médicament vérifiable par batch ID pendant la démonstration.
  • Interfaces sobres, lisibles, adaptées à chaque rôle et fonctionnelles sans MetaMask pour la lecture.
